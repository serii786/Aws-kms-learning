# 🔐 AWS KMS - Key Management Service

> Secure • Manage • Encrypt Your Data in the Cloud

## 📌 What is AWS KMS?
AWS KMS ek managed service hai jo encryption keys ko create, manage aur control karne ke liye use hoti hai.

## ✨ Key Features
- 🔒 Encryption at Rest - S3, EBS, RDS
- 🔑 Centralized Key Management
- 🔄 Automatic Key Rotation
- 📋 Audit & Compliance via CloudTrail
- 🛡️ IAM + Key Policies for Granular Control
