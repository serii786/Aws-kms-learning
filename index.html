What is AWS KMS?

AWS KMS ek service hai jo encryption keys ko create, manage aur control karti hai. Bina key ke koi tumhara data read nahi kar sakta.

  • ✅ Encryption at Rest - S3, EBS, RDS
  • ✅ Centralized Key Management
  • ✅ Automatic Key Rotation
  • ✅ Audit via CloudTrail
